# Almotakamila Flexible Packaging Website

A bilingual corporate website developed for Almotakamila Flexible Packaging, a flexible packaging manufacturer based in Baghdad, Iraq.

## Live Website

[Visit](https://motakamila.iq)

## Project Overview

The project involved redesigning and launching Almotakamila’s corporate website with a modern visual identity, responsive layouts, bilingual content, and a clearer presentation of the company’s products, industries, capabilities, and manufacturing process.

## My Role

As IT Manager, I led the website planning, technical implementation, testing, deployment, and coordination of the final launch.

## Key Responsibilities

- Website planning and information architecture
- WordPress theme implementation
- Arabic and English content structure
- Right-to-left Arabic layout support
- Responsive design and mobile testing
- Interactive animations and visual effects
- Staging environment and deployment
- SEO, caching, image optimization, and performance setup
- Backup and recovery planning
- Final website testing and launch

## Key Features

- Arabic and English interfaces
